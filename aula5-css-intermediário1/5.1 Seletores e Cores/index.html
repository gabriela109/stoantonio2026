Seletores e Cores

Estou aprendendo a usar CSS para deixar minhas páginas mais bonitas, organizadas e com a minha personalidade. Aos poucos, vou entendendo como cada propriedade transforma a aparência do conteúdo.

Nesta atividade, aprendi que posso destacar uma parte importante do texto usando uma classe. Escolhi uma cor especial para chamar a atenção de quem está visitando a página.

Com os seletores certos, consigo personalizar cada parte da página de uma maneira diferente. Isso facilita a criação de layouts mais interessantes e deixa o conteúdo mais fácil de ler.

Aqui fica a parte principal do conteúdo. Usei um ID para identificar essa área e aplicar nela uma cor de fundo específica, mostrando como o CSS também pode destacar uma seção inteira.
